Aide

Assistance de Sur6 (app iPhone, app Android et app web Notes)

Nous écrire : info@sur6.ch. Réponse en général en quelques jours. Ne nous envoie jamais ton code de synchronisation.

Sur6 est le projet personnel d'un élève. Application non officielle : seul ton bulletin fait foi.

Questions fréquentes

J'ai perdu mon code de synchronisation.

Personne ne peut le retrouver pour toi : nous ne le connaissons pas. Si un de tes appareils est encore relié, ouvre Réglages → Synchronisation → « Copier le code ». Sinon, tes notes sont toujours sur ton appareil : active la synchronisation à nouveau pour obtenir un nouveau code.

Je change de téléphone. Comment garder mes notes ?

Deux façons. Soit Réglages → Synchronisation sur l'ancien téléphone, puis « J'ai déjà un code » sur le nouveau. Soit Réglages → Sauvegarde → Exporter, puis « Importer un fichier » sur le nouveau (avec ou sans les photos).

J'utilisais l'app web. Mes notes sont-elles dans l'app de l'App Store ?

Non, l'app de l'App Store garde ses notes à part. Dans l'app web, active la synchronisation et copie le code, puis dans Sur6 : Réglages → Synchronisation → « J'ai déjà un code ». Une sauvegarde (Exporter, puis Importer un fichier) marche aussi.

Les notifications n'arrivent pas.

Elles demandent la synchronisation. Dans Réglages → Notifications, active « Recevoir les notifications » et vérifie que « Tout couper » est éteint. Autorise ensuite les notifications de Sur6 dans les réglages du téléphone.

Comment supprimer mes données ?

Réglages → Synchronisation → « Supprimer mes notes du serveur » efface tout ce que le serveur garde pour ton code. Supprimer l'app efface le reste. Détails dans la page Confidentialité.

Ma moyenne n'est pas la même que sur mon bulletin.

Vérifie d'abord ton profil (Réglages → Profil) et les coefficients de tes notes. Si l'écart reste, signale-le sur la page Plaintes et améliorations ou par e-mail, avec tes notes mais sans ton nom.

Est-ce une app officielle de mon gymnase ?

Non. Sur6 est faite par un élève, sans lien avec une école ou l'administration. Elle suit les règlements publiés, mais ses résultats sont indicatifs : seul ton bulletin fait foi.
