Confidentialité : tes notes restent chez toi

Ce que l'app enregistre, et où

En bref. Pas de compte, pas de publicité, pas de mesure d'audience. Tes notes sont enregistrées sur ton appareil. Rien ne part sur Internet, sauf si tu actives la synchronisation, et même alors tout est chiffré avant l'envoi : le serveur ne peut pas lire tes notes.

Sur ton appareil

  • Ton profil (voie, année, options), tes notes et tes réglages sont dans le stockage local du navigateur ou de l'app installée.
  • Les photos de tes tests restent sur l'appareil. Elles ne sont jamais synchronisées ni envoyées.
  • Si tu supprimes l'app ou les données du site, tout disparaît. Pense à faire une sauvegarde (Réglages → Sauvegarde) : c'est un fichier que tu gardes où tu veux.

Synchronisation entre appareils (facultative)

  • Tu crées un code de synchronisation de 16 caractères et tu le tapes sur ton autre appareil.
  • Le code sert à la fois d'adresse et de clé : tes notes sont chiffrées sur ton appareil (AES-GCM, clé dérivée du code), puis envoyées. Le serveur ne reçoit que des données chiffrées et une empreinte du code, jamais le code lui-même.
  • Qui a ton code peut lire tes notes : ne le partage pas.

Notifications (facultatives)

Avec la synchronisation, l'app peut prévenir tes autres appareils d'une nouvelle note. Le message est chiffré avec la même clé ; c'est ton appareil qui le déchiffre pour l'afficher.

Ce site

Ce site de présentation n'utilise ni cookies ni outils de statistiques. Il est hébergé par GitHub Pages, qui, comme tout hébergeur, voit l'adresse IP des visiteurs.

Notes est un projet indépendant, fait par un élève. Il n'est ni édité ni validé par le canton ou par un gymnase. Application non officielle. Résultats indicatifs : seul ton bulletin fait foi.
